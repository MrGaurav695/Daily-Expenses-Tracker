# Expense Tracker

A simple and responsive **Expense Tracker** built using **HTML, CSS, and JavaScript**.  
This project helps users keep track of their daily expenses by adding descriptions, categories, amounts, and viewing totals.

---

## ✨ Features
- Add expenses with description, category, and amount.
- Support for custom categories.
- Responsive UI for desktop and mobile.
- Real-time total calculation.
- Option to delete expenses.
- Stores date for each expense (auto-added in the background).

---

## 🛠️ Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling & Responsiveness  
- **JavaScript (Vanilla JS)** – Functionality
